# SCOREMARK サポートページ

アプリ「SCOREMARK」（野球スコアブック）のトップ・サポート・プライバシーポリシーのページです。
ほかのアプリと同じく、GitHub Pages で公開する（このフォルダの中身を公開用のリポジトリに置く）。

- トップ：index.html
- サポート：support.html
- プライバシーポリシー：privacy.html

画面の写真（images/）は iPhone 17 Pro Max・iPad Pro 11 インチのシミュレータで確認用の起動口（tool/preview_main.dart）を開いて撮ったもの。paper.jpg は iPad を縦にして「紙のスコアブック」の画面を撮り、紙の部分だけを切り出したもの。
アプリの見た目が変わったら撮り直す。

外部のフォント・スクリプトは読み込まない（プライバシーポリシーとの整合のため）。
アプリの機能や扱うデータが変わったら、privacy.html も直す（App Store の「App のプライバシー」の回答とも合わせる）。
